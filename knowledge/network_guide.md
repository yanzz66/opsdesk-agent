
# 示例企业办公网络使用指南

> 本文为 OpsDesk Agent 演示知识，不代表真实企业政策。

## 办公网络连接

员工连接办公网络时，应使用公司批准的网络。

如果无法访问互联网，可以：

1. 检查 Wi-Fi 是否连接成功。
2. 检查电脑是否获得正常的 IP 地址。
3. 尝试访问其他网站。
4. 根据设备管理要求重新连接网络。

## DNS 故障

如果网络已经连接，但是无法访问域名，
需要检查 DNS 解析是否正常。

员工可以记录错误信息并提交 IT 支持工单。

## 网络安全注意事项

禁止私自关闭公司安全软件，
或未经授权修改网络安全策略。

如果怀疑发生网络攻击，
应立即联系企业安全支持人员。
